# FEED

FEED is an archived prototype for a social networking and digital-asset platform. The project explored a branded landing page, dashboard screens, wallet connection flows, and related interface concepts.

## Project status

This is a dead-end project and is not being actively developed. Work stopped because of regulatory issues, deficiencies in the code and overall implementation, and a lack of funding. There are no plans to launch or maintain it as a product.

## What’s in this repository

- `index.html` — the main landing-page and interface prototype.
- `dashboard.html` — a standalone dashboard concept.
- `wallet_connect.html` — a wallet connection interface concept.
- `test_my_firestore.html` — a Firestore test page.

The pages are primarily standalone HTML and rely on several third-party assets loaded from CDNs. Some screens contain illustrative or placeholder content; their balances, transactions, integrations, and market information should not be taken as real or verified.

## Viewing the prototype

Open `index.html` in a browser. An internet connection is needed for externally hosted fonts, styles, icons, and other assets. The other HTML files can also be opened directly.

## Important note

This repository is retained as a record of work on an unfinished prototype. It is not production-ready and must not be used to handle real assets, funds, credentials, or personal information. No security, regulatory, or operational assurances are provided.
